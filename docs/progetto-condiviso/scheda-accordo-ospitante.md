# Scheda di confronto e accordo con una realtà ospitante

**Modello da validare con l'ospitante e con professionisti prima dell'uso.**
Non è un contratto pronto per la firma. Copiare il modello fuori da Git prima
di inserire nomi, recapiti, importi o firme.

## 1. Parti e natura del rapporto

| Voce                                            | Da definire nella copia operativa                                                 |
| ----------------------------------------------- | --------------------------------------------------------------------------------- |
| Realtà ospitante e referente                    |                                                                                   |
| Referente del nucleo Tao Veda                   |                                                                                   |
| Natura del rapporto                             | Affitto sala / iniziativa organizzata dall'ospitante / collaborazione da definire |
| Organizzatore responsabile verso i partecipanti |                                                                                   |
| Titolarità della comunicazione pubblica         |                                                                                   |

Descrivere in modo esplicito se l'ospitante mette soltanto a disposizione lo
spazio o organizza l'iniziativa. La disponibilità della sala non trasferisce
automaticamente responsabilità operative, fiscali o assicurative.

## 2. Attività

| Voce                                    | Da definire |
| --------------------------------------- | ----------- |
| Titolo e scopo realistico               |             |
| Data, orari e durata                    |             |
| Destinatari e requisito di maggiore età |             |
| Numero minimo e capienza massima        |             |
| Attività di studio                      |             |
| Pratica personale                       |             |
| Eventuale contatto fra persone          |             |
| Attività escluse                        |             |
| Conducente e competenze dichiarate      |             |

Se è previsto contatto corporeo, allegare l'esito del Gate 2B del runbook. Se
il gate non è chiuso, indicare espressamente che l'attività sarà individuale e
senza contatto fra partecipanti.

## 5. Economia e documentazione

| Voce                                                 | Da definire |
| ---------------------------------------------------- | ----------- |
| Costo dello spazio o altri costi                     |             |
| Quota o contributo richiesto ai partecipanti         |             |
| Soggetto che incassa                                 |             |
| Documento emesso e trattamento fiscale da verificare |             |
| Spese rimborsabili e approvazione preventiva         |             |
| Modalità e tempi di pagamento                        |             |
| Gestione di annullamenti e restituzioni              |             |

Nel pilota non sono previsti compensi ai promotori. Un importo obbligatorio non
viene definito donazione. Incassi e rimborsi seguono le regole del soggetto
organizzatore dopo verifica professionale.

## 6. Assicurazioni e responsabilità

| Voce                                           | Conferma scritta richiesta |
| ---------------------------------------------- | -------------------------- |
| Polizza dell'ospitante applicabile all'evento  |                            |

| Esclusioni, massimali e adempimenti            |                            |
| Copertura del conducente o degli organizzatori |                            |

Non usare formule generiche come “coperto dall'associazione”: indicare polizza,
attività, soggetti e conferma ricevuta nella copia riservata.
